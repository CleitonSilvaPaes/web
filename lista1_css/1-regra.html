Atividade 1 – O que é uma regra CSS?

Conceito: Uma regra CSS (CSS Rule) é a estrutura fundamental da linguagem CSS (Cascading Style Sheets). Trata-se de uma instrução fornecida ao navegador para localizar elementos específicos na árvore do documento (DOM) e aplicar-lhes estilos visuais (como cores, dimensões, fontes, espaçamentos e posicionamentos).

Estrutura de uma Regra CSS

Toda regra CSS é composta essencialmente por duas partes principais:

  1. Seletor (Selector): Identifica a quais elementos HTML a regra deve ser aplicada.
  2. Bloco de Declarações (Declaration Block): Delimitado por chaves { }, contém uma ou mais declarações. Cada declaração é um par composto por uma Propriedade e um Valor, separados por dois-pontos : e finalizados com ponto e vírgula ;.

Exemplo Prático

/* Regra CSS: Altera a cor e o tamanho do título principal */ h1 { color: #e74c3c; /* Propriedade: color | Valor: #e74c3c */ font-size: 28px; /* Propriedade: font-size | Valor: 28px */ text-transform: uppercase; /* Propriedade: text-transform | Valor: uppercase */ }

Detalhamento dos Componentes

Componente No Exemplo Função / Descrição
Seletor h1 Define que todos os elementos <h1> do documento receberão este estilo.
Propriedade color Especifica qual aspecto visual será modificado (neste caso, a cor da fonte).
Valor #e74c3c Determina a configuração a ser atribuída à propriedade (o tom de vermelho).
