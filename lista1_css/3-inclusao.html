Atividade 3 – Como podemos incluir CSS em documentos HTML?

Existem três formas principais de aplicar folhas de estilo CSS a um documento HTML. Cada uma atende a cenários e necessidades específicas no desenvolvimento web:

1 CSS Externo (External Style Sheet)

As regras CSS são escritas em um arquivo dedicado com a extensão .css (ex: estilo.css). Esse arquivo é vinculado ao HTML através da tag <link>, inserida dentro do elemento <head>.

Vantagens: Separação limpa entre estrutura (HTML) e apresentação (CSS); o mesmo arquivo pode estilizar centenas de páginas do site; permite cache no navegador acelerando o carregamento.
Recomendação: É a melhor prática da indústria para projetos e sites completos.
<head> <meta charset="UTF-8"> <title>Exemplo Externo</title> <!-- Vinculação do CSS externo --> <link rel="stylesheet" href="estilo.css"> </head>

2 CSS Interno ou Incorporado (Internal / Embedded)

As declarações CSS ficam reunidas dentro da tag <style>, posicionada no <head> do próprio documento HTML.

Vantagens: Excelente para páginas de layout único, páginas de aterrissagem (landing pages isoladas) ou testes rápidos sem gerar novos arquivos no servidor.
Desvantagens: As regras não podem ser compartilhadas automaticamente com outras páginas HTML, exigindo duplicação de código.
<head> <style> body { background-color: #f0f2f5; } h1 { color: #2c3e50; text-align: center; } </style> </head>

3 CSS Em Linha (Inline Styles)

Os estilos são inseridos diretamente no elemento HTML alvo através do atributo global style="...".

Vantagens: Aplicação imediata e de alta especificidade sobre um único elemento.
Desvantagens: Mistura estrutura com estilo, dificulta severamente a manutenção, não permite reaproveitamento e polui o código-fonte.
Uso típico: E-mails em HTML (devido a restrições de clientes de e-mail) ou manipulação dinâmica via JavaScript.
<!-- Estilo aplicado diretamente na tag do elemento --> <p style="color: #e74c3c; font-weight: bold; background: #ffeaa7; padding: 10px;"> Este parágrafo possui estilização CSS inline direta. </p>

Quadro Comparativo

Método Local de Inserção Escopo Recomendação de Uso
Externo Arquivo .css via <link> no <head> Múltiplas páginas Padrão obrigatório para sites e aplicações reais.
Interno Dentro de <style> no <head> Página atual inteira Páginas com estilo exclusivo ou protótipos rápidos.
Inline Atributo style="..." na tag Apenas o elemento específico E-mails HTML ou sobrescritas cirúrgicas pontuais.
