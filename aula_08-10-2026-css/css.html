CSS

Css é uma linguagem declarativa auxíliar a documentos html para estilização de definição de comportamento. O css pode ser declarado de três formas distintas.

  1. Ná tag style, definida no cabeçario do HTML;
  2. Em um documento externo por meio da tag link;
  3. Inline no proprio elemento HTML

CSS possui diversas formas de selecionar em quais elementos html uma regra será aplicado

Seletores:
  • seletor por elemento.
  • * seleor univesal.
  • # id identificador unico.
  • .classe ou categoria
  • " " seletor por descente A B
  • ">" seletor para filho direto
