Internet e Web

A Internet é a rede mundial que conecta computadores e dispositivos. A Web é um serviço que funciona sobre a Internet e permite acessar páginas por meio de navegadores. A Web utiliza tecnologias como HTML e HTTP. Portanto, Internet é a infraestrutura, enquanto Web é um dos serviços que utilizam essa infraestrutura.

Principais Conteúdos Estudados até Agora

  • div → elemento utilizado para agrupar conteúdos.
  • nav → elemento utilizado para representar uma área de navegação.
  • main → elemento que representa o conteúdo principal da página.
  • br → elemento utilizado para criar uma quebra de linha.
  • header → elemento utilizado para representar o cabeçalho de uma página.
  • p → elemento utilizado para criar parágrafos.
  • a → elemento utilizado para criar links.
  • span → elemento inline utilizado para agrupar ou destacar pequenos trechos de texto.
  • sub → apresenta um texto abaixo da linha normal. Exemplo: H2O.
  • sup → apresenta um texto acima da linha normal. Exemplo: x2.
  • mark → destaca um trecho de texto. Exemplo: texto destacado.
  • del → representa um texto removido ou excluído. Exemplo: texto removido.
