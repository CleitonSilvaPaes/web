Internet e Web

A Internet é a rede mundial que conecta computadores e dispositivos. A Web é um serviço que funciona sobre a Internet. Ela permite acessar páginas por meio de navegadores. A Web usa tecnologias como HTML e HTTP. Portanto, Internet é a infraestrutura, e Web é uma aplicação dessa infraestrutura.

Principais Conteúdos Estudados até Agora

  • "div" -> um conteiner
  • "nav" -> um tag de navegação
  • "main" -> é um conteiner de definição de principal
  • "br" -> uma tag de quebra de linha
  • "header" -> uma conteiner que fala pro navegador que é cabeçalho
  • "p" -> - tag de paragrafo
  • "a" para criar link
  • "span" -> É um elemento inline. Ocupa apenas o espaço do texto e aceita propriedades de largura e altura apenas se alterado para display: inline-block.
  • "sub" -> (Subscript / Subscrito): Renderiza o texto abaixo da linha regular, com um tamanho de fonte menor. É usado principalmente para fórmulas químicas (como H₂O) ou índices matemáticos.
  • "sup" -> (Superscript / Sobrescrito): Renderiza o texto acima da linha regular, com um tamanho de fonte menor. É usado para potências matemáticas (como x²), notas de rodapé ou abreviações (como 1º).
  • "mark" -> (Texto Marcado): Representa um texto destacado ou realçado para fins de referência, devido à sua relevância em um determinado contexto. Por padrão, os navegadores aplicam um fundo amarelo a este elemento. É muito útil para destacar termos pesquisados pelo usuário.
  • "del" -> (Texto Deletado): Representa um texto que foi removido ou excluído do documento. Por padrão, os navegadores exibem esse texto com uma linha tachada (riscada ao meio). É ideal para mostrar o histórico de edições ou atualizações de preços.
