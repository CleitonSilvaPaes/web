O que é HTTP?

HTTP significa Hypertext Transfer Protocol, ou Protocolo de Transferência de Hipertexto. Ele é um protocolo utilizado para realizar a comunicação entre clientes e servidores na Web.

Quando uma pessoa acessa um site pelo navegador, o navegador envia uma requisição HTTP para um servidor. O servidor processa essa solicitação e envia de volta uma resposta HTTP.

Portanto, podemos representar a comunicação da seguinte maneira:

Navegador → Requisição HTTP → Servidor

Servidor → Resposta HTTP → Navegador

Cliente e servidor

Cliente

O cliente é o dispositivo ou programa que solicita algum recurso de um servidor. Na Web, um exemplo de cliente é o navegador, como Chrome, Firefox, Edge ou Safari.

Servidor

O servidor é o computador ou sistema responsável por receber as requisições e fornecer os recursos solicitados. Esses recursos podem ser páginas HTML, imagens, arquivos ou dados.

Requisição

A requisição HTTP é uma mensagem enviada pelo cliente ao servidor solicitando uma ação ou recurso.

Resposta

A resposta HTTP é a mensagem enviada pelo servidor de volta ao cliente após o processamento da requisição.

Como funciona uma comunicação HTTP?

  1. O usuário digita o endereço de um site no navegador.
  2. O navegador identifica o servidor responsável pelo site.
  3. O navegador envia uma requisição HTTP.
  4. O servidor recebe e processa a requisição.
  5. O servidor envia uma resposta HTTP.
  6. O navegador interpreta a resposta e apresenta o conteúdo ao usuário.

Métodos HTTP

Os métodos HTTP indicam qual ação o cliente deseja realizar sobre determinado recurso.

Método GET

O método GET é utilizado principalmente para solicitar dados de um servidor.

Por exemplo, quando o usuário acessa: 

GET /index.html HTTP/1.1
Host: www.exemplo.com

O navegador está solicitando ao servidor o arquivo index.html.

Método POST

O método POST é utilizado para enviar dados ao servidor. É comum em formulários, cadastros, logins e outras operações que precisam enviar informações.

Por exemplo, um formulário de cadastro pode enviar nome e e-mail através de uma requisição POST. 

POST /cadastro HTTP/1.1
Host: www.exemplo.com
Content-Type: application/x-www-form-urlencoded

nome=Joao&email=joao@exemplo.com

Exemplo de uma requisição HTTP

Abaixo temos um exemplo simplificado de uma requisição HTTP utilizando o método GET: 

GET /produtos.html HTTP/1.1
Host: www.exemplo.com
User-Agent: Mozilla/5.0
Accept: text/html

Nesse exemplo:

  • GET: indica o método utilizado.
  • /produtos.html: é o recurso solicitado.
  • HTTP/1.1: indica a versão do protocolo.
  • Host: informa o servidor que está sendo acessado.
  • User-Agent: informa características do cliente.
  • Accept: indica o tipo de conteúdo aceito pelo cliente.

Exemplo de uma resposta HTTP

Depois de receber e processar a requisição, o servidor pode responder da seguinte forma: 

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 125

<html>
    <body>
        <h1>Olá!</h1>
    </body>
</html>

Nesse exemplo, o código 200 informa que a requisição foi processada com sucesso. O servidor também informa que o conteúdo retornado é um documento HTML.

Códigos de status HTTP

Os códigos de status HTTP são números enviados pelo servidor para informar o resultado de uma requisição.

Principais códigos de status HTTP
Código Nome Significado
200 OK A requisição foi processada com sucesso e o servidor conseguiu fornecer o recurso solicitado.
301 Moved Permanently O recurso foi movido permanentemente para outra URL. O cliente pode ser direcionado para o novo endereço.
302 Found Indica um redirecionamento temporário para outro endereço.
400 Bad Request O servidor não conseguiu entender ou processar corretamente a requisição enviada pelo cliente.
403 Forbidden O servidor entendeu a requisição, mas não permite o acesso ao recurso solicitado.
404 Not Found O servidor não encontrou o recurso solicitado. É comum quando uma página não existe ou foi removida.
500 Internal Server Error Ocorreu um erro interno no servidor ao tentar processar a requisição.
Os códigos HTTP ajudam o cliente a entender o resultado de uma requisição.

Resumo

O HTTP é fundamental para o funcionamento da Web. Ele define como clientes e servidores trocam informações através de requisições e respostas.

  • Cliente: solicita recursos.
  • Servidor: fornece recursos e processa solicitações.
  • Requisição: mensagem enviada pelo cliente.
  • Resposta: mensagem retornada pelo servidor.
  • GET: normalmente utilizado para obter dados.
  • POST: normalmente utilizado para enviar dados.
  • Status HTTP: informa o resultado da requisição.
