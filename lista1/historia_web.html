A Evolução da Internet e da Web

Histórico Geral

A Internet e a Web possuem trajetórias distintas. Internet é a infraestrutura física e de protocolos, enquanto a Web é a camada de aplicação onde navegamos.

Citação sobre a Web

"A World Wide Web é uma maneira de acessar informações através da rede" – Tim Berners-Lee (criador da Web no CERN).

Linha do tempo da Internet e da Web

  1. Surgimento das redes de computadores

    Durante as décadas de 1950 e 1960, surgiram diferentes formas de conectar computadores para compartilhar informações e recursos. Essas pesquisas contribuíram para o desenvolvimento das redes que posteriormente dariam origem à Internet.

  2. 1969 – ARPANET

    A ARPANET foi uma das primeiras grandes redes de computadores baseada em comutação de pacotes. Criada com apoio da agência norte-americana ARPA, ela conectou inicialmente instituições de pesquisa e universidades.

  3. 1983 – TCP/IP

    Em 1983, o conjunto de protocolos TCP/IP passou a ser utilizado pela ARPANET. Ele permitiu que diferentes redes pudessem se comunicar, sendo fundamental para o crescimento da Internet.

  4. 1984 – DNS

    O DNS (Domain Name System) foi desenvolvido para facilitar a utilização da Internet. Em vez de memorizar endereços numéricos, os usuários passaram a poder utilizar nomes de domínio, como example.com.

  5. 1989 – Proposta da World Wide Web

    Em 1989, o cientista britânico Tim Berners-Lee, trabalhando no CERN, apresentou uma proposta para criar um sistema de informação baseado em hipertexto que posteriormente se tornaria a World Wide Web.

  6. 1990 – HTML, HTTP e servidor Web

    Tim Berners-Lee desenvolveu componentes fundamentais da Web, incluindo o HTML, o protocolo HTTP e o primeiro servidor Web. Esses elementos permitiram criar, armazenar e acessar documentos interligados pela Internet.

  7. 1990 – Primeiro navegador

    Também foi desenvolvido o primeiro navegador Web, inicialmente chamado WorldWideWeb. Os navegadores são programas que permitem ao usuário acessar e visualizar páginas e aplicações Web.

  8. Web 1.0

    A chamada Web 1.0 era predominantemente formada por páginas estáticas. O usuário geralmente apenas consumia as informações disponibilizadas pelos sites.

  9. Web moderna

    As aplicações Web modernas são muito mais interativas. Elas podem permitir login de usuários, armazenamento de dados, comunicação em tempo real, vídeos, compras e diversas outras funcionalidades. Tecnologias como JavaScript, APIs e bancos de dados são utilizadas para criar experiências mais dinâmicas.

Recursos e Destaques

A Web permitiu a expansão do acesso à informação, a criação de sites e o crescimento da comunicação online. Tim Berners-Lee foi o responsável por idealizar esse sistema, que transformou a maneira como usamos a Internet.

O termo World Wide Web significa teia mundial e se tornou uma das maiores invenções da história digital. O uso de hipertexto foi fundamental para conectar páginas de forma não linear.
