GIT

O git é um sistema de controle de versão distribuida.

Comandos git

  • git init : inicializa um repositório git
  • git status : mostra o status
  • git add arquivo.txt : Adiciona o arquivo no stage (rascunho)
  • git commit -m "comentario" : cria um commit no sei repositório local
  • git log : exibe os commits da branch atual do repositório local
  • git switch branch : muda de branch
  • git switch -c cria-nova-branch : muda de branch
  • git diff : exibe a diferença do commit apontado por HEAD e worktree
